Wallpaper Engine 视频壁纸模板
发布版文档日期：2026-11-03

用途
把已经制作好的视频，套用到“视频循环 + 鼠标视差 + 可调立体时钟”壁纸中。
以后换视频无需修改 HTML、CSS 或 JavaScript。先下载并解压模板，准备一次制作工具，再复制模板作为每个作品的工作文件夹。

最快使用方式
1. 在 GitHub 仓库选择 Code → Download ZIP，或下载提供的 ZIP 项目包，并完整解压到本地文件夹。不要直接在压缩包里运行程序。
2. 首次制作前，联网双击“准备制作工具.cmd”，等待 FFmpeg / ffprobe 下载及校验完成。工具保存在本模板内，不需要系统安装。
3. 复制准备好的整个模板文件夹，给副本起一个新作品名称；每个视频使用独立工作副本。
4. 双击副本内的“替换视频.cmd”选择视频，或将视频文件拖到这个程序上。
5. 等待工具提示成功。工具会生成本地播放用的 WebM，同时更新海报和预览图。
6. 双击“安装为新项目.cmd”。工具会查找 Steam 库，在 Wallpaper Engine 的 myprojects 下新建独立目录。
7. 打开 Wallpaper Engine，在“已安装”中选择新项目。若列表没有刷新，关闭再打开壁纸选择器；仍看不到时，用壁纸编辑器打开工具输出目录里的 project.json。
自动安装找不到 Wallpaper Engine 时，将 wallpaper 文件夹复制到实际安装位置的 projects\myprojects\ 下并使用独立新目录名；不要把 tools 或备份复制进去。
只有首次取得制作工具需要联网；工具准备完成后的换视频处理在本地进行，壁纸运行始终不依赖网络。只运行随附演示壁纸时，无需先下载 FFmpeg。

更详细的步骤、参数和故障处理请双击“操作手册.html”。它可以完全离线阅读，也可以从浏览器打印。

模板里保留的效果
• 双播放器提前解码与短淡入衔接，包含片尾保护和快速暂停恢复修复。
• 平滑鼠标反向视差，按位移计算覆盖范围。
• 固定于屏幕的半透明时钟，可调大小、不透明度、位置、时区、12/24 小时制和秒显示。
• 鼠标经过时钟时，时钟平滑滑动和倾斜；效果可关闭或调节。
• 默认北京时间 UTC+8，按真实系统时间刷新，独立于 Windows 本地时区。
• 壁纸运行不联网，不需要另开转换工具或其他程序。

素材要求
使用至少 2 秒的 SDR 视频。16:9、3840×2160 在 4K 桌面上最合适。
工具不强制放大分辨率，不插帧；常规素材保留尺寸和帧率，特殊像素比例或奇数尺寸会作兼容性规范化。它不会把低清视频变成真正的 4K 细节；输出默认静音。
符合兼容条件的 VP8/VP9 WebM 可使用快速复制路径；MP4 等格式需要实际转换为 VP9 WebM，耗时取决于片长、分辨率和电脑性能。不要仅把 .mp4 改名为 .webm。
不同比例使用保持比例的居中 cover 裁切，画面不会被拉伸；竖屏或超宽素材会有部分内容被裁掉。模板不会自动识别人脸或主体，时钟位置可在 Wallpaper Engine 中调整。
短淡入能柔化循环衔接，但不能保证任意素材的首尾动作、镜头和姿态都完全无缝。

文件分工
wallpaper\             真正的壁纸项目；只有这个目录需要安装或发布。
wallpaper\assets\video.webm  固定的运行视频入口。
wallpaper\assets\poster.jpg  当前视频的启动海报。
wallpaper\preview.jpg  Wallpaper Engine 列表/发布预览图。
wallpaper\project.json  项目标题、入口与用户设置定义。
tools\                 制作期工具；不需要复制到 myprojects 或随壁纸发布。
准备制作工具.cmd       首次联网下载并校验本地 FFmpeg / ffprobe。
替换视频.cmd           选择/拖入新视频，更新视频及两张配套图片。
安装为新项目.cmd       为此作品建立新的本地项目目录，不切换当前桌面，也不上传。
说明.txt / 操作手册.html  本说明及完整使用手册。

关于已有作品和工坊
模板没有预设的工坊条目关联。附带视频及配套图片用于演示。
制作工具不修改源视频、不更新其他已有作品，也不会自动发布 Steam 创意工坊。
转换成功前不会替换现有壁纸素材；备份位于 wallpaper 目录之外，便于回退且不会混入发布包。
恢复工作副本时，从 backups\时间戳\ 中取出 assets\video.webm、assets\poster.jpg、preview.jpg 和 project.json，放回 wallpaper 的同名位置。此恢复步骤不要用于覆盖已发布项目的 project.json。
每次“安装为新项目”都会创建独立副本。此后再改工作文件夹，不会自动改变已经安装的副本。
若要更新自己创建的同一个作品，请按手册同步 video.webm、poster.jpg 和 preview.jpg，保留那个项目自己的 project.json；不要覆盖它的工坊编号。

适用环境与验证
基于 Wallpaper Engine 2.8.42 Steam 版 Web 项目的已验证实现整理。
新视频应在导入后自行检查几个循环、鼠标四角、时钟遮挡及暂停恢复；此前的模板验证不代表所有未来素材都已验证。
普通浏览器只能检查网页画面，最终桌面输入、暂停及性能以 Wallpaper Engine 中实际运行结果为准。

代码、素材与第三方工具
此版本尚未为模板代码及演示素材另行指定开源许可证；公开仓库不等于自动授予开源许可。
演示素材未附加开源许可。制作新作品时请换成自己可使用、可发布的视频。
FFmpeg 是独立第三方制作工具，按其自身许可证提供。来源、版本与许可说明见 tools\第三方工具说明.txt。
发布到 Steam 创意工坊时，只使用 wallpaper 中的壁纸运行内容，不上传制作工具、备份或源视频。
